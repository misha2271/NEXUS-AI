# NEXUS AI 1.0 — предварительная версия

[English](README.md). Продолжение локализованной v0.4 в ветке
`feature/nexus-ai-v1.0`, draft [PR #4](https://github.com/misha2271/NEXUS-AI/pull/4).
Русский включён по умолчанию. В **Настройки → Язык** можно сразу переключиться
на English; выбор сохраняется между запусками.

## Работающие возможности

- **Game Center:** добавление, редактирование и удаление игр с точными именами
  EXE через точку с запятой. Настройки сохраняются. Фоновое обнаружение включается
  пользователем; запуск игры включает игровой профиль, завершение возвращает
  выбранный основной профиль. Никакие процессы не завершаются.
- **Ollama:** выбор модели, потоковый чат и четыре профиля сохранены.
  Автовыгрузка выключена для новой игры: пользователь отдельно разрешает её.
  Допустима только модель, успешно использованная текущим сеансом NEXUS на этом
  сервере; запросы выполняются через документированный API. Один экземпляр той же
  модели может использоваться другим клиентом Ollama — выгрузка повлияет и на него.
  После игры загрузка выполняется по запросу, без автоматического занятия VRAM.
- **Диалоги:** завершённые ответы сохраняются в локальную SQLite-базу; диалог
  можно продолжить, начать заново или удалить. Прерванные ответы не сохраняются
  в контекст. Данные хранятся открытым текстом на компьютере пользователя.
- **SSD:** чтение Windows Storage Reliability Counters. Доступны только реальные
  показатели накопителя и драйвера; отсутствующие поля отмечены недоступными.
  Износ означает использованный ресурс, а не вычисленный «процент здоровья».
- **Геймпады:** снимок стандартных слотов XInput: кнопки, триггеры и стики.
  Номер слота не доказывает, что подключён Elite Series 2. Управление вибрацией,
  лепестками и прошивкой не реализовано.
- **Обновления:** проверка стабильных GitHub Releases официального репозитория.
  Скачивание требует подтверждения, размера и SHA-256 из метаданных GitHub;
  для новой основной версии требуется дополнительное согласие. Проверка хеша
  не является цифровой подписью автора. Автоустановка отключена.

## Экспериментальные основы и ограничения

Кнопка **Голос и удалённый доступ** находится в помощнике. Работают только явно
разрешённые текстовые команды: «статус», «стоп», «игровой режим», «умный режим»,
«максимум ИИ», «эко режим». Аудиодвижок не поставляется; микрофон и озвучка отключены
до подключения проверенного провайдера.

Удалённый интерфейс выключен по умолчанию. Случайный токен отображается только
после запуска и не сохраняется. Разрешены только статус, остановка ответа и смена
профиля. HTTP разрешён на loopback для локальной проверки; для доступа iPhone по
локальной сети нужны собственный доверенный TLS-сертификат и настройка сети.
Физическая проверка на iPhone ещё не проведена.

MSI Mystic Light, Logitech G560 и охлаждение исследованы по официальным источникам.
Инвентаризация Windows может найти названия устройств, но это не подтверждает
работоспособность SDK. RGB, вентиляторы, аудио и прошивки остаются отключёнными.
Температура CPU в Windows недоступна без поддерживаемого датчика; значения
CPU/GPU/RAM/VRAM и графики никогда не подменяются фиктивными данными.

## Запуск, сборки и проверки

Python 3.11+, `python -m pip install -e ".[dev,nvidia]"`, затем `python -m nexus_ai`.
Ollama должен быть установлен и запущен отдельно. Для тестов:
`python -m pytest -q`, `python -m ruff check .`,
`python -m ruff format --check .`, `python -m compileall -q src`.

Windows EXE и Portable ZIP создаёт workflow **Windows executable builds** только
после проверок, нативной сборки и запуска обоих EXE без установленного Python.
Артефакты находятся на странице успешного запуска GitHub Actions; вход в GitHub
может требоваться. Это тестовые сборки с ограниченным сроком хранения, не релиз.
Актуальные результаты и ссылки: [проверка v1](docs/v1-validation.md).

## Установщик Windows

Нативный workflow готовит `NEXUS-AI-Setup-1.0.0.exe` из проверенной переносимой
сборки. Используйте артефакт только успешного запуска Actions. Установка выполняется
для текущего пользователя без прав администратора; доступны русский и английский.
Python и Qt входят в комплект, Ollama и модели устанавливаются отдельно.
Перед загрузкой артефакта CI должен выполнить тихую установку, дважды запустить
установленный EXE без Python в PATH и удалить программу. Удаление сохраняет
пользовательские настройки и диалоги. Контрольная сумма включается в SHA256SUMS.
Сборки не подписаны: поведение SmartScreen нужно проверить вручную.
